Task 3 – SQL for Data Analysis

## Objective
Use SQL queries to extract, manipulate, and analyze structured data.

## Dataset
TV_Final.csv – TV/e-commerce product dataset.

## Tools Used
- SQLite
- SQL
- CSV Dataset

## Analysis Performed

- Subqueries
- JOIN operations
- Views
- Query optimization using indexes

## Files
- TV_Final.csv – Original dataset
- Task3_SQL_Queries.pdf – SQL queries used
- Task3_SQL_Outputs.pdf – Query results and analysis outputs

## Outcome
The task demonstrates practical SQL skills for data extraction, analysis, aggregation, and interpretation.
